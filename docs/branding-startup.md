Settings → Appearance → App startup offers Windowed or Fullscreen. `AppSettings.StartupFullscreen` defaults to false for existing/new settings files, saves immediately through the existing settings store, and applies to the next graphical app launch. Windowed retains saved window placement, including a maximized window. Fullscreen invokes the existing F11 behavior. Two animation frames allow rendered tiles to lay out before a 450ms crossfade: the splash fades out while the app fades from zero to full opacity. The splash uses the established React portal pattern so it remains outside the app's opacity layer. Empty catalogues and frontend loading errors also release the splash. It runs once per WebView session, so page navigation and language/layout reloads do not replay it. Background controls are inert and document scrolling is blocked only while the splash is present; both restore after dismissal. Reduced motion removes both fades and the minimum presentation delay.
